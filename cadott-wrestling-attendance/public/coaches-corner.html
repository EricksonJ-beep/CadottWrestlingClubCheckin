Administrative tools for managing attendance data and settings.

Reset Attendance History

Clears all stored practice dates and check-in records. Athletes remain, but season stats will reset. This cannot be undone.

Tip: Export CSV first if you want a backup.

Reset Today's Check-ins

Removes ONLY today’s check-in data so you can start over for the current practice. Previous days remain intact.

Today will disappear from season stats until new check-ins occur.

Submit Today's Attendance

Locks all check-ins for today so they cannot be changed. Use at end of practice.

After submission, check-in buttons become read-only for today.

Export Attendance CSV

Download season attendance in pivot format (dates as columns). Useful before a reset.

Roster Refresh

Manually pull the latest roster from the linked Google Sheet.

Season Stats Overview

View aggregate group performance and per-athlete season attendance.
